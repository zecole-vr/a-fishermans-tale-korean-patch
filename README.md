# A Fisherman’s Tale 한글 패치

**VR 유튜브 크리에이터 제콜이 제작한 비공식 한글 패치입니다.**

## 패치 내용

- 게임 자막 한글화
- 메뉴, 설정, 조작 안내 및 로딩 화면 등 인터페이스 한글화
- 한글 가독성을 위한 글꼴·자막 크기와 거리 조정
- Quest 3 환경에 맞춘 컨트롤러 안내 표시

영어 음성은 유지됩니다. Steam PCVR 버전용이며, Quest 단독 실행판에는 사용할 수 없습니다. 컨트롤러 안내는 Quest 3 기준입니다. 일부 번역은 플레이 검수에 따라 개선될 수 있습니다.

## 다운로드

이 저장소의 **Releases**에서 배포 ZIP을 받으세요. `Code → Download ZIP`은 설치용 배포 파일이 아닙니다.

**압축 비밀번호: `zecole`**

## 설치법

1. 게임을 완전히 종료합니다.
2. 다운로드한 ZIP을 비밀번호 `zecole`로 **전부 압축 해제**합니다. 압축 파일 안에서 바로 실행하지 마세요.
3. 압축을 푼 폴더의 **`Install.cmd`를 더블클릭**합니다.
4. Steam 설치 경로를 자동 검색합니다. 찾지 못하면 게임 폴더 `A Fisherman's Tale`을 선택해 주세요. Steam 라이브러리의 게임 → 관리 → 로컬 파일 탐색에서 위치를 확인할 수 있습니다.
5. 권한 요청 창이 나타나면 허용합니다. 설치 완료 메시지가 나온 뒤 게임을 실행합니다.
6. 게임의 화면 언어와 음성 언어는 **English**, 자막은 **켜짐**으로 설정합니다.

기본 Steam 경로 외의 라이브러리도 검색합니다. 자동 설치가 어려우면 `patch` 폴더의 `Fisherman-KoreanSubtitles_P.pak`을 게임 폴더의 `Fisherman\Content\Paks`에 복사해 주세요. 같은 이름의 알 수 없는 패치가 있다면 먼저 따로 보관하세요.

## 복구법 — 한글 패치 제거

1. 게임을 완전히 종료합니다.
2. 압축을 풀었던 폴더의 **`Restore.cmd`를 더블클릭**합니다.
3. 완료 후 실행하면 게임의 원래 영어 표시로 돌아갑니다.

원본 게임 파일은 교체하지 않고 추가 한글 PAK만 설치합니다. 수동으로 복구하려면 `Fisherman\Content\Paks\Fisherman-KoreanSubtitles_P.pak`만 삭제하세요. **`Fisherman-WindowsNoEditor.pak`은 원본이므로 삭제하지 마세요.**

설치 프로그램이 인식하는 이전 한글 패치를 교체할 때에는 게임 폴더의 `zecole-patch-backups`에 사본을 남깁니다. 복구 프로그램은 영어 원본으로 돌아가기 위해 한글 PAK를 제거하며, 이전 한글 버전을 다시 설치하지는 않습니다. 다른 모드나 별도 음성 교체까지 복구하는 도구는 아닙니다. 게임 업데이트 후 문제가 생기면 패치를 제거한 뒤 Steam 파일 무결성 검사를 진행해 주세요.

## 글꼴

한글 표시에 **나눔고딕(Nanum Gothic)**을 사용했습니다. 자막에는 일반 굵기, 메뉴와 조작 안내에는 굵은 글꼴을 적용했습니다. Windows에 글꼴을 별도로 설치할 필요가 없습니다.

나눔고딕은 NHN Corporation의 글꼴이며 **SIL Open Font License 1.1**을 따릅니다. 라이선스 전문은 배포 파일의 `licenses/NanumGothic-OFL.txt`에 포함돼 있습니다.
